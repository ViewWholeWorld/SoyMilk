**3.9.0 已于北京时间 2026-10-23 23:43:57 部署。** 内网和 Tailscale 入口的真实登录、今天／7 天／30 天统计 API 与页面渲染均通过，原统计页 500 已恢复。镜像、备份、数据保护与性能边界见下方[生产发布](#生产发布)。

本轮把后台统计收敛到实际用量：显示总 token、输入 token、输出 token、请求数，按供应商／模型分布，并提供北京时间“今天”“7 天”“30 天”和自定义日期范围。7 天和 30 天包含当天；每日趋势同时给出输入、输出和请求数，缺失用量继续显示未知或部分数据。

线上 `/admin/model-stats` 曾因 PostgreSQL 共享内存不足返回 500（错误码 `53100`，数据库容器 `/dev/shm` 仅 64 MB）。检查时数据盘仍有约 168.1 GB 空闲，不能把该错误理解为数据盘已满。候选查询将汇总、模型分组和每日分组合并为一次只读扫描，并在事务内关闭并行 worker，避免同页多个并行查询同时申请共享内存。设置只在本事务生效；候选项读取不再加载无关的预算／队列汇总。

## 统计口径与兼容

- 按实际发生的 live attempt 计数；同一请求的重试分别计数，复用已有回执不增加请求；排除评测、导入、回放及非模型服务。
- 北京时间开始包含、结束排除；快捷范围包含今天，自定义范围包含选择的结束日，最多 90 天。默认今天在午夜可返回空范围，缺失日期补零。
- 总 token 为已知输入与输出之和；缺报或非法用量保持未知／部分，不补成有效零。汇总和每日趋势不受模型分页影响。
- 保留供应商、连接、用途及模型筛选；旧费用书签转换到适用的用量筛选，旧价格书签返回模型配置。快捷范围切换显式退出自定义编辑态。
- 不新增迁移、不删除价格表／历史金额／历史回执。新请求仅在既有 JSON 列记录归属和冷却依据，既有回执复用不改写历史快照。
