保留 SoyMilk 名称、五个兴趣领域、42 个 RSS、44 个主题、分类、评分权重和门槛、私网 HTTP、模型账号及默认强度。保留预算、稳定请求身份、未知回执等待、共享回执消费者恢复、许可事务撤回、报告完整输入依赖。并发仍为 2，不重新评分历史文章，不批量付费重写事件，不开启飞书或 IndexNow。

前端仅通过 HTTP 读取 API；公开出口继续使用 `publication/`。测试使用虚构凭据、关闭的环境开关、本进程本地模型替身、内部网络和独立 `_test` 空库；不得加载生产环境、授权或数据。不恢复 CI、自动同步或自动部署。

## 版本与变更日志契约

现有根 package.json 未定义应用版本，OpenAPI 描述版本为 `3.0.0`，网站 `latestVersion` 使用日期时间。建立以下规则：

1. 根 package.json、package-lock.json 根包、网站日志顶层 `version`、最新日志条目的 `version`、OpenAPI `info.version` 同步维护。
2. `latestVersion` 继续使用北京时间日期时间格式，供原有导航红点使用，不改为 SemVer。
3. 网站日志增加可选版本显示，历史条目不补造版本。开发日志记录实现与验证，网站日志面向读者说明行为，不写内部调试细节。
4. 功能递增 MINOR，修复递增 PATCH；各阶段完成时版本依次为 `3.1.0`、`3.2.0`、`3.2.1`、`3.2.2`、`3.3.0`、`3.4.0`、`3.4.1`。
5. 阶段记录明确区分开发完成和验证完成。候选版本号不代表 NAS 已上线；更新后必须以现场镜像核验确认发布。

## 1. 精选时间线只看未读（3.1.0）

上游参考：`15bc417`、`652bd6b`。

- 新增默认关闭的「只看未读」开关，使用本站已有浏览器本地已读记录，不创建账户或上传阅读行为。
- 普通卡片按自身 ID 判断；阅读组只要当前筛选范围内仍有未读精选成员就保留，不能只看代表文章。
- 后端组信息增加可选 `memberIds`，复用当前成员查询；普通报道、筛选范围外内容和撤回内容不进入成员集合。
- 已加载卡片全部已读时继续翻页，但遵守现有三批自动加载上限，随后由读者点击「加载更多」。失败保留重试，不无限请求。
- 返回列表保留开关、已加载数据、折叠与位置；兼容旧快照缺少新字段。切换筛选不复用错误的成员范围。
- 未读模式的计数只统计当前可见卡片，空态区分「当前批次都读过」和「没有未读内容」。

验收：单篇、阅读组、全部已读、分页上限、失败重试、筛选范围、历史返回；类型、构建、网页测试及时间线数据库回归通过。

## 2. 阅读字体选择（3.2.0）

上游参考：`ff23271`，只提取字体相关部分。

- 在现有阅读设置增加「网站默认字体／浏览器默认字体」，继续保存在本机。
- 首帧脚本应用选择，避免加载后字体跳变；跨标签页变更和导入后同步。
- 本地存储拒绝写入时，本标签页仍可使用选择；不损坏已有收藏、已读和外观数据。
- 导出格式增加可选字体字段，导入旧备份仍可用；已有本机选择优先。
- 不改变代码块等已有专用字体，不重新引入已下线导航入口。

验收：偏好默认值、写入失败、跨标签更新、旧备份兼容和导入导出；类型、构建及网页回归通过。

## 3. 事件归组与回执原子提交（3.2.1）

上游参考：`9229843`，适配本站较早归组结构。

- 将归组决策、成员归属、归组状态与所用付费回执完成放在同一 PostgreSQL 事务。
- 复核人工归属、输入版本过期、当前许可变化等提前返回分支；已取得结果的回执保持可复用和可恢复。
- 事务失败不留下「业务已提交、回执仍等待」状态，也不能把尚未提交的业务标记完成。
- 不更换请求身份、不放宽预算、不删除历史回执；文章公开投影继续按现有流程更新。

验收：数据库故障注入验证业务和回执一起回滚，重试复用原模型响应；人工归属、正常归组和未知回执恢复回归通过。

## 4. RSS／Atom 文本解析（3.2.2）

上游参考：`50b562b`、`309e32e`，只移植相关解析修复。

- Atom 默认或显式 `type=text` 按纯文本保留，不能把原文字面尖括号当 HTML 标签删掉；HTML、XHTML、CDATA 和实体按各自格式处理。
- 来源明确设置 `summaryIsBody=true` 时支持短正文，Atom 与 RSS 一致；未配置的来源仍区分摘要、预告和正文。
- 保持原文链接、URL 判重身份、RSS 验证器、时区、七天窗口和初次每源两条限制。
- 不顺带采用上游 48 小时存档规则，不开启全文许可，不改 Jina 后备和等待保护。

验收：本地模拟 RSS/Atom 请求，涵盖短正文、文本尖括号、XML 实体、HTML/XHTML、空正文、预告和条件请求；采集与内容许可相关回归通过。

## 5. 事件综述先讲结论及评测工具（3.3.0）

上游参考：`fd51bcf`，按本站依赖追踪实现适配。

- 综述先说明主体、核心变化和当前结果，再用短段补背景、分歧和限制；保留事实约束、矛盾归属及不可信输入边界。
- 保留本站 `latest` 和已有数据库/API 契约，不直接采用上游删除字段的输出结构。
- 提取生产综述输入构造供评测复用，保留完整 provenance、增量前提校验、40 篇窗口和保存前许可复核。
- 增加快照导出和同一输入的提示词对比工具。导出只读、不调用模型；比较调用明确受 `--max-calls`、站内预算及回执约束，结果不写回事件。
- 工具默认不批量重写；提示词随新增报道自然生效。既有事件无新输入时不因版本变更触发付费请求。

验收：输入复用、调用数上限、失败记录、结果复用、无事件写回；综述撤回、输入变化、人工标题、增量更新及完整回归通过。隔离测试只用本地替身；本轮不做生产付费评测，实际文风提升需日后阅读验证。

## 6. 信源健康诊断（3.4.0）

上游参考：`50b562b`、后续 `sources/health.ts` 修复。

- 在已有后台运行告警中报告近七天反复失败、七天无新发现、发布日期缺失、反复材料修订和详情补全失败。
- 区分编辑来源与热度信号，计入独立发现，不将成功 HTTP 请求当作有产出。
- 排除预算等待和正常进程停止，不将其误计为真实失败。显示截断时保留总数。
- 无产出提示要求对照原站，不自动停用低频来源或调整策略；关闭采集时不发出采集诊断。
- 继续使用现有告警等级、后台展示和已关闭的飞书开关，不新增定时任务或通知渠道。

验收：边界日期、低频静默、间歇失败、预算/停止排除、独立发现、缺日期/反复修订、信息数量上限；后台运行和告警相关回归通过。

## 7. 阅读与热点性能优化（3.4.1）

上游参考：`9d5de21`、`931a4eb`，按本站结构拆分。

- 长文章目录限制高度并独立滚动，处理键盘和滚轮到边界，不让目录挤出阅读区域。
- 代码高亮等增强按需要加载，正文文字和复制功能立即可用；清理观察器，避免返回页面重复增强。
- 热点只为可见头像携带图片地址和 srcSet，保留完整参与者名称与总数；不改变热度算法、公开许可和来源顺序。
- 对已存在的返回位置恢复进行回归，保留时间轴说明。
- 上游整套页面数据缓存不直接搬入：本站撤回与缓存版本检查有更严格契约。本轮以按需加载和减少有效载荷实现性能收益；更长期页面缓存需另案设计许可失效机制，本计划不引入。

验收：长目录和键盘行为、代码复制/懒加载/返回清理、热点头像有效载荷、名称和总数、移动端与桌面版式；构建和网页测试通过。
