## 资源与命名约定

- 图片集中在[资源／图片](资源/图片/)，信源示例集中在[资源／信源示例](资源/信源示例/)。图片和示例保留原文件名、格式与内容；本机示例服务的运行方法见信源接入文档。
- 新文档放入对应中文分类，使用明确的中文文件名；版本记录可使用 `版本号-主题.md`，一次性记录可使用 `YYYY-MM-DD-主题.md`。移动或重命名时同步 Markdown 链接、说明中的路径和引用元数据，并更新本索引。
- 操作指南说明当前使用方式；计划明确标注实施状态；历史记录保留当时的决定和证据。历史中的“待实现”“未合并”、旧镜像和运行计数只描述当时阶段，不能作为当前操作步骤。
- 实时状态以维护说明提供的只读查询为准，生产迁移和配置修改仍遵守现有授权流程。
