# 模型配置、统计与费用

本文说明源码候选 `3.5.2` 的使用方式：`/admin/models` 管理配置，`/admin/model-stats` 查看统计。包含新增迁移 `0048`，尚未正式迁移或部署；实施与验收见[3.5.2 记录](3.5.2优化内容.md)，升级按[手动部署](manual-deploy.md)执行。

NAS 最近已核验版本仍为北京时间 2026-10-16 上线的 `3.5.1`，其配置、价格和费用同在 `/admin/models`，已完成迁移 `0045`—`0047` 与参考目录初始化，未自动补算；证据见[维护说明](soymilk-operations.md#2026-10-16-模型定价正式上线)。以下新入口在切换新版后生效。

## 配置入口与供应商

“模型与能力”标签管理 Codex 账号、API Key 连接、默认连接、能力模型分配与推理强度，历史切换记录默认折叠。配置页不查询用量、费用或补算；“模型价格”标签打开后才读取价格和本地目录。SelectBench 继续使用已有独立入口。

连接编辑中的“服务供应商”指实际提供调用服务的平台，中转站不按模型名或参考价来源推断归属。可选择已有供应商或新增，名称去首尾空白、合并连续空白并统一大小写后去重。已确认的官方接口提供默认归属，Codex／ChatGPT 对应 OpenAI，阿里云国内／国际对应同一供应商；价格仍按连接与地区保存。选择“供应商未知”后会保留明确的空归属，后续不自动覆盖。

新请求在价格快照旁记录供应商 ID。以后更换或删除连接都不改变已有请求的归属；旧记录仅将固定 `subscription:codex`／`subscription:chatgpt` 标识映射 OpenAI，其他缺失保持未知，不按当前配置回填。供应商编辑不改变连接 generation、请求键或回执复用。

## 设置连接价格

价格按稳定连接 ID 与请求型号保存。同名模型使用不同连接时可以有不同价格；切换默认、重命名或删除连接不会重新分配历史费用。

在“模型价格”中选择连接与型号，点击编辑：

- **参考价**：从本地 models.dev 目录搜索，明确填写供应商 ID 与型号 ID。支持第三方别名人工映射，但不按同名型号猜测供应商。
- **自定义**：输入完整的一套价格，至少填写输入、输出；缓存读取、写入可留空。支持先复制参考价再修改。币种支持 USD / CNY，单位均为每百万 token，最多八位小数；空白是未知，`0` 是免费。
- **恢复参考价**：检查映射与四类有效单价后确认。清除整套自定义价格，保留映射并记录审计。价格版本冲突时先重新读取，不覆盖其他管理员的修改。

缓存写入填写完整单价，不填附加费。多档缓存时长、上下文阶梯及无法表达的计价项标为不支持，需核对适用条件后改为自定义并备注。推理单价等于输出单价的目录项可用，推理 token 不重复计入输出。

已确认的官方 HTTPS 接口与精确请求型号支持默认映射：OpenAI、DeepSeek、阿里云国内／国际、智谱、小米 MiMo；Codex / ChatGPT 映射 OpenAI。完整匹配规则见 `providers/model-billing.ts`；自定义路径、HTTP、中转站、附带查询参数的地址不自动映射。默认映射也需要本地存在受支持的目录条目，不会在请求中下载价格。

新请求在发送前保存价格快照，响应及用量保存时计算。改价、改映射和目录更新只影响后续请求；回执复用没有新费用，重试的各次实际请求分别计价。计价不会修改请求身份、账号、推理强度、并发或预算。

## 报价币种

每条连接／型号单独选择美元（USD）或人民币（CNY），人民币别名 RMB 在目录导入时统一为 CNY。请按供应商该接口、该地区的实际报价填写，不能凭供应商位于国内或国外推定币种。同一供应商的不同地区或渠道也可能使用不同币种。

参考模式采用目录币种，自定义模式由管理员明确选择。切换币种只改变单价所用的货币，不会自动换汇；复制美元参考价后若选择人民币，须重新核对并填写四类人民币单价，不能只换货币符号。

每个请求的价格快照保存当时币种；后来把规则从 USD 改成 CNY，或参考目录更新币种，只影响新请求。费用与历史补算分别按 USD／CNY 汇总，不生成跨币种总额；实际金额与估算币种不一致时各自展示。未知币种保持未知，不当成人民币或美元。

## 同步与查看参考目录

点击“同步参考目录”才会读取固定的 `https://models.dev/api.json`。页面加载、价格查询、模型请求及后台任务不自动同步。部署网络需允许该地址；不需要模型密钥。models.dev 当前约定未声明币种的价格为 USD / 每百万 token，国内供应商的参考价也遵循这一约定；不能据名称把同一数字改成人民币。目录显式声明的 USD / CNY 会原样保留，RMB 规范为 CNY，声明可位于供应商、模型或 cost 的 currency；多处声明必须一致。无效、不支持或冲突币种会使同步失败并保留旧目录，不默认为美元。适配依据及许可证见[冻结夹具来源](../tests/fixtures/models-dev-prices.md)。

同步使用条件请求、超时、响应大小限制、同源重定向限制和原子发布。失败保留旧目录；新目录中消失的条目保留最后成功值并提示失效，超过七天提示陈旧。自定义价格不随同步变化。同步不代表供应商价格承诺，账单仍应以供应商为准。

## 调用与用量

在 `/admin/model-stats` 默认查看“调用与用量”，另一标签为“费用”。两者共用时间、供应商和请求型号筛选，“更多筛选”中选择连接或用途。默认最近七天，也可选择 24 小时、30 天或北京时间自定义日期；结束日包含整天，内部按 attempt 的 `started_at` 使用开始包含、结束不包含的范围。普通刷新会更新快捷范围，日期选择不变；URL 保存标签和筛选，改筛选后从第一页开始。

同供应商、同请求型号的连接、用途及提示版本合并为一行，不同供应商或型号分别展示。每页默认 20 行，按调用次数降序，相同时按供应商 ID 和型号稳定排序。顶部汇总使用完整筛选范围。供应商未知组只表示缺少信息，不代表这些请求来自同一平台。

每次实际 live attempt 计一次，重试分别计数，复用回执不新增；导入、回放、SelectBench 和非模型请求不参与。成功率沿用 `received`，表示收到响应，不保证业务处理成功。p50／p95 从有效已完成耗时重算。输入、输出分别保留已报告的合法数值，全缺失显示未知，部分缺失显示“部分数据”；明确零值显示 0。

缓存率只使用输入总数与缓存读取数同时有效的请求，以缓存读取总量除以这些请求的输入总量；缺失不计作未命中，负数或缓存超过输入的非法样本排除。无有效分母显示未知。推理 token 不重复加入输出，辅助明细可在“查看请求明细”中读取。首轮处理或预算恢复有进行中／异常状态时，在统计页显示简要信息。

## 参考费用与金额未知

费用只汇总已保存的金额和价格快照，不用最新报价重算历史。有合法非负实际金额且币种明确时优先采用，否则采用完整或近似估算；只有部分估算或没有合法金额时统一为“金额未知”。实际与估算不重复相加，明确零费用正常保留，缺用量不影响已有实际金额。

每个供应商／型号仍只有一行，行内按原币种和 API／订阅 API 等价／计费类别未知分项。USD、CNY 和其他明确币种分别列示，不换汇相加；订阅等价不代表实际扣款。页面注明“费用仅供参考，未知金额未计入”。

纯未知组合默认收起，显示组合数与未知调用数；“显示金额未知项”后加入同一张表、同一套分页。显示与隐藏、翻页都不改变顶部完整范围汇总。全部金额未知时显示“当前范围金额未知”，无调用时显示“暂无调用”，不会把两者写成零费用。

点击组合或“查看请求明细”后才查询原始请求，附带供应商、型号和时间。费用状态、币种和计费类别筛选仅在明细中提供，不改变普通汇总；部分金额、用量和错误信息在明细保留。超时或响应丢失但可能已扣费的请求，无可用金额就保持未知，后续重试不替代旧请求金额，不为补齐数据重发请求或自动对账。

## 历史补算

费用标签中的“高级：历史费用补算”打开后才加载运行列表、补算所需价格和可选运行明细，正常统计不读取或混入补算结果。旧价格、费用和补算书签会跳转到对应页面／标签并保留适用筛选。

先选择日期与可选服务／型号，点击“只读预览”。默认只选缺少定价或用量的 live 记录，历史 imported 须主动勾选，replay 始终排除。

已保存连接归属的请求沿用原归属与原计费类别。旧请求没有归属时，可添加明确的服务、旧型号、独占时间段、目标连接型号、该时间段的计费类别及至少十字的证据。同一服务与型号的映射区间不能重叠；未提供证据或多解时保持未知，不套用当前默认连接。

预览冻结价格与请求 ID 上界，最多计算前 500 条样本并显示前 40 条明细；超过样本上限时，样本金额不是全范围总额。价格或选择范围发生变化后须重新预览。创建运行时固定请求集合；之后分批处理，每批最多 200 条，网页使用 100 条。可暂停、关闭页面、重启进程后继续，同一运行不会重复计入。

每轮结果写在独立表，保存冻结价格、用量 hash、归属证据、计算版本与原因。选择某一轮查看其金额，轮与轮不叠加。原请求、实际金额、用量、回执状态及预算均不改写，也不会重新调用模型。进行中的请求保持缺少用量；补算后才完成的用量可以另开一轮核对。

补算使用当前冻结价格，不能恢复当时的历史报价；缺失的缓存明细和 `0022` 导入前丢失的重试明细不能恢复。它是辅助估算，不是历史账单。

### 命令行

必须显式提供目标 `DATABASE_URL`。输入文件只含范围与证据，不含密钥：

```json
{
  "filters": {
    "from": "2026-09-30T16:00:00Z",
    "to": "2026-10-15T16:00:00Z",
    "includeImported": false,
    "missingOnly": true,
    "service": "llm"
  },
  "mappings": []
}
```

先设置数据库连接环境变量，再执行：

```sh
node scripts/model-cost-backfill.ts dry-run --input range.json --out preview.json
node scripts/model-cost-backfill.ts execute --input preview.json --request-id <固定UUID> --max-batches 20 --batch-size 100
node scripts/model-cost-backfill.ts resume --run-id <运行UUID> --max-batches 20 --batch-size 100
```

dry-run 不建运行、不写结果；execute 使用预览并输出运行 ID，重复执行相同 UUID 幂等。SIGINT / SIGTERM 等当前批事务完成后停止，后续用 resume 继续。预览文件包含历史元数据，工具以 `0600` 写入，勿提交 Git。

设置 `MODEL_COST_BACKFILL_ENABLED=false` 并重启 API 或 CLI 可关闭新预览、创建和执行，正常请求定价及已有结果读取继续可用。无定时补算任务。
