# 结构引文评测

工具仅评测单项结构、P2a 理解合并、P2b 摘要合并；不评分、不写入 analyses、不归组、不回填历史。本次只修复工具与测试，**没有执行真实模型评测**，不代表引文质量或人工阈值通过。

## 冻结导出

源连接由调用者显式提供，不读取 `.env`。导出事务固定为 `REPEATABLE READ READ ONLY`，只选择当前 revision、已 analyzed 且分析非 stale 的材料；在同一快照冻结完整 `AnalyzeInputArticle`、日期、旧分析输出、文案、提示词与回执引用。仅本步骤读取源文章。

```sh
DATABASE_URL="$SOYMILK_EXPORT_DATABASE_URL" node scripts/eval-structure-evidence.ts --export --out work/structure-cases.jsonl --days 14 --seed 7
```

按疑似综合／限定条件／普通单事件抽样 15／15／10，固定种子可重复；导出可不足，但不能用少量样本代替正式评测。已有文件不覆盖。快照含原文，只存于私有、忽略的 `work/`，不提交、不打印。

## 隔离调用与恢复

本轮明确禁止真实模型调用；历史授权不适用于本轮，以下调用说明不构成执行授权。

先准备迁移完成的独立库，库名以 `_test` 或 `_ci` 结尾。调用者必须在进程环境显式提供 `SOYMILK_EVAL_DATABASE_URL`；工具先校验它，再设置 `DATABASE_URL`，之后才动态导入 backend，不回退使用原 `DATABASE_URL`。不通过命令参数传入连接，不输出变量实际值，不读取凭据文件。实测从 JSONL schema 恢复日期及输入，不再读取源文章。隔离库的模型配置和授权应由操作者另行准备，工具不复制源库配置、改预算或开安全阀。

```sh
node scripts/eval-structure-evidence.ts --cases work/structure-cases.jsonl --max-calls 50 --out-dir work/structure-evidence-eval
```

调用前验证恰好 40 篇、15／15／10 配额、caseId／articleId 唯一、输入与基线 ID／revision 一致、max-calls 为 40—50。整批路径预检失败、配置不兼容、摘要不能合并时显式拒绝，不回落到单项结构。固定输入／提示词版本身份和模型配置摘要写入 manifest；每篇开始及回执占位、终态结果分别持久记录。全部开始尝试计入硬上限，receipt_attempts 单独统计实际请求及未知用量；一般间隔至少 20 秒，限流等待至少 60 秒，恢复继续沿用等待时间。

默认输出目录为已忽略的 `work/structure-evidence-eval`；旧默认 `outputs/structure-evidence-eval/` 也被精确忽略，其他 `outputs/` 不受影响。自定义目录同样须避免提交含原文的快照。

只沿原 JSONL、隔离库和输出目录恢复。隔离库的评测专属 settings 键登记各文章修订的目录与身份，占位前被安全阀／鉴权等拒绝也不能换目录重开；这些键不修改模型配置。既有回执由 `logical_key` 经 `receiptAttemptTag` 提取固定轮次及步骤，并与用途核对归属，不改写 `receipts.request`。目录锁排他；崩溃残留 `.lock` 时，须人工确认原进程已结束且逐篇记录完整后处理锁。结束行（含格式失败和拒绝）跳过；已有开始占位而没有终态的行保留 unknown、跳过，不自动再发。事务内的 `onReserved` 锁定文章修订并检查全部评测路径的既有回执，禁止借新轮次、目录、版本或模型重发已有尝试。不要删除隔离库或逐篇记录来重开评测，不释放 unknown、不删除付费记录；保留不确定性供人工处理。

结果文件关联 `cases.jsonl` 的输入哈希、旧分析基线及实际路径，保留引文校验前后、计数、receipt、失败与截断未知；`summary.json` 及合并的 `results.jsonl` 可重建，逐篇结果只追加。旧 schema 字段缺失仍兼容为 null／空数组，不能据此判为质量通过。所有结果均待人工核对原文、事实归属、综合稿范围、条件完整性、截断和误删，再审核阈值；有限样本不能外推总体质量。

## 人工质量门槛（#102）

运行成功仅代表工具完成执行，不代表质量通过。固定 40 篇（疑似综合／限定条件／普通单事件为 15／15／10），对照冻结原文与旧文案逐项记录以下结果：

- 格式失败不超过 2／40；没有因新增字段造成的截断，截断元数据缺失单列未知，不能算作未截断。
- 被判为综合稿的文章全部人工核对；误判最多 1 篇，普通单事件须 0 误判。
- 丢弃引文占校验前引文总数的比例不超过 30%。
- 抽查 20 条引文，至少 18 条确实支持对应事实；连续匹配通过不能代替事实支持性判断。
- 条件层相比旧文案最多丢失 1 条，且至少 5 篇文章的条件有可查引文。

未知项保留未知，不以工具成功、兼容默认值或历史样本补作通过证据。本轮不执行真实评测。
